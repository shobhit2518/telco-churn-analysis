# 📊 Telco Customer Churn Analysis & Prediction

An end-to-end Data Science project predicting customer churn using Python, exploratory data analysis, statistical hypothesis testing, and machine learning models.

## 🚀 Project Overview
Customer churn is a critical challenge for telecommunication companies. This project analyzes historical customer data to uncover why customers leave, validates assumptions using statistical tests, and builds predictive machine learning models to identify high-risk customers proactively.

## 📂 Project Structure
- `week1_analysis.ipynb`: Data acquisition, missing value imputation, cleaning, and initial EDA.
- `week2_analysis.ipynb`: Advanced visualizations (KDE, boxplots, payment methods analysis).
- `week3_analysis.ipynb`: Statistical analysis & hypothesis testing (Independent T-Test & Chi-Square).
- `week4_analysis.ipynb`: Supervised ML model training & evaluation (Logistic Regression, SVM, Random Forest, XGBoost).
- `reports/`: Folder containing official weekly Word documentation (.docx).

## 📊 Key Findings & Results
- **EDA Insights:** Short-tenure customers with high monthly charges and month-to-month contracts exhibit the highest churn propensity.
- **Statistical Validation:** Hypothesis testing proved a statistically significant relationship between monthly billing/contract types and churn behavior ($p < 0.05$).
- **Model Performance:** Logistic Regression and Support Vector Machine (SVM) achieved the highest predictive accuracies of **81.97%** and **81.41%** respectively.
